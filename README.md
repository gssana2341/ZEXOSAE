# ZEXOSAE

ต้นแบบเกมมุมมองบุคคลที่ 1 บนเว็บ เน้นความเร็วและการควบคุม ใยดึงตัวขึ้นไปยังจุดที่เล็ง และยิงโดนศัตรูตามเป้าที่หันเมาส์ไป ยิงโดนนัดเดียว KO

มีโหมดซ้อมคนเดียว และโหมดออนไลน์แบบเดธแมตช์ได้สูงสุด 16 คนต่อห้อง ยังไม่มีล็อกอิน Google ชื่อและคะแนนรวมจึงเก็บในเบราว์เซอร์ของผู้เล่น และจะหายถ้าล้างแคช

## เล่นกับเพื่อน

```bash
npm install
npm run online
```

คำสั่งนี้สร้างเกมแล้วเปิดเซิร์ฟเวอร์ที่พอร์ต 3000 ในเทอร์มินัลจะแสดงที่อยู่สำหรับเปิดเกม

1. เปิดเกม กด `เล่นออนไลน์` เลือกจำนวนผู้เล่น แล้วกด `สร้างห้องใหม่`
2. เพื่อนเห็นห้องในบอร์ด `ห้องที่เปิดอยู่` แล้วกด `เข้า` หรือใส่รหัส 4 ตัวก็ได้
3. ระหว่างเล่น กด Esc แล้วกด `คัดลอกลิงก์ชวนเพื่อน` เพื่อส่งลิงก์ และกด Tab ค้างเพื่อดูคะแนน

ทุกห้องแสดงในบอร์ด ใครที่เปิดเกมจากเซิร์ฟเวอร์เดียวกันจะเข้าได้

เพื่อนที่ต่อ Wi-Fi เดียวกันใช้ที่อยู่ `Network` ที่ขึ้นต้นด้วย `192.168.` ได้เลย ส่วนเพื่อนที่อยู่คนละที่ต้องเปิดเซิร์ฟเวอร์ให้เข้าถึงจากอินเทอร์เน็ตก่อน

## ขึ้น Vercel

Vercel เก็บตัวเกมได้ แต่เซิร์ฟเวอร์ห้องต้องอยู่ที่อื่น เพราะห้องเก็บไว้ในหน่วยความจำ ผู้เล่นแต่ละคนอาจถูกส่งไปคนละ instance และการเชื่อมต่อบน Vercel มีเวลาจำกัด

1. เปิดเซิร์ฟเวอร์ห้องด้วย `npm run online` บนเครื่องที่เปิดค้างไว้ และทำให้เข้าถึงจากอินเทอร์เน็ตผ่าน https
2. ใน Vercel ตั้ง Environment Variable ชื่อ `VITE_SERVER_URL` เป็นที่อยู่ เช่น `wss://your-server.example.com/ws`
3. Deploy ใหม่ทุกครั้งที่เปลี่ยนค่านี้ เพราะค่าถูกฝังตอน build

ถ้าไม่ตั้งค่านี้ โหมดซ้อมยังเล่นได้ แต่โหมดออนไลน์จะเชื่อมต่อไม่ได้

## พัฒนาเกม

| คำสั่ง | หน้าที่ |
| --- | --- |
| `npm run dev` | เปิดเกมแบบแก้โค้ดแล้วรีเฟรชเอง ที่ `http://localhost:5173` |
| `npm run server` | เปิดเซิร์ฟเวอร์ห้องสำหรับใช้คู่กับ `npm run dev` |
| `npm run online` | สร้างเกมและเปิดเซิร์ฟเวอร์สำหรับเล่นจริง |
| `npm run build` | สร้างไฟล์เกมไว้ใน `dist/` |
| `npm run typecheck` | ตรวจ TypeScript |
| `npm test` | ทดสอบฟิสิกส์ กติกา และระบบห้อง |

## สัญญาณเตือนรอบจอ

ถ้าศัตรูเล็งมาที่เราค้างไว้ และไม่มีกำแพงบัง ขอบจอฝั่งที่ศัตรูอยู่จะเรืองแสงสีแดง ขอบบนคือข้างหน้า ขอบล่างคือข้างหลัง ยิ่งศัตรูใกล้ยิ่งสว่าง ในโหมดซ้อม หุ่นจะผลัดกันเล็งมาเพื่อให้ฝึกหลบ ปรับค่าได้ใน `DANGER` ที่ `src/sim/danger.ts`

## กติกาออนไลน์

- ยิงโดนนัดเดียว KO ถ้าอยากให้ทนกว่านี้ ปรับ `PLAYER_HP` ที่ `src/net/protocol.ts`
- ถูก KO แล้วเกิดใหม่ใน 3 วินาที โดยสุ่มจาก 28 จุดทั่วแมป ไม่ซ้ำจุดเดิม ห่างจากคนอื่นอย่างน้อย 30 เมตรเมื่อทำได้ และยิงไม่โดน 1.5 วินาทีแรก
- ใยรัดตัดใยของคนที่โดน ใช้ใยไม่ได้ และเดินช้าลงประมาณ 1.6 วินาที
- เกมของคนยิงเป็นผู้รายงานการยิงโดน เซิร์ฟเวอร์ตรวจแค่ระยะและอัตราการยิง จึงเหมาะกับเล่นกับเพื่อน แต่ยังกันโกงไม่ได้เต็มที่

| ดึงตัวด้วยใย | คลิกขวาค้าง | กดปุ่มโหนค้าง |
| ยิงใย | คลิกซ้าย | แตะปุ่มยิง |

เปลี่ยนปุ่มคอมได้ในหน้าตั้งค่า การวิ่งบนกำแพงเริ่มเองเมื่อแตะผนังสีเขียวขณะลอยอยู่

ใยจะเกาะจุดกลางจอก่อน ถ้าเล็งพลาดเล็กน้อยจะหาจุดใกล้ๆ ให้ และถ้าปิดช่วยเล็งจะเกาะจุดกลางจอเท่านั้น ระหว่างลอยอยู่ ให้กด W ค้างแล้วหันเมาส์เพื่อเลี้ยวทิศทาง

ช่วยเล็งทำงานตอนยิง: เมาส์จะหนืดลงเมื่อเป้าเข้าใกล้ศัตรู และถ้าใกล้มากจะล็อกตามสั้นๆ 0.35 วินาที ก่อนล็อกใหม่ได้ต้องรอ 0.9 วินาที ขยับเมาส์แรงๆ เพื่อหลุดได้ทันที ปรับค่าได้ใน `AIM` ที่ `src/sim/aim.ts` และปิดได้ในหน้าตั้งค่า กรอบเล็งแสดงเฉพาะโหมดซ้อม

## โครงสร้าง

- `src/sim/` ฟิสิกส์และกติกา ไม่พึ่ง Three.js หรือ DOM เพื่อให้เซิร์ฟเวอร์ออนไลน์นำไปใช้ซ้ำได้
- `src/sim/player.ts` ค่าปรับความรู้สึกทั้งหมดอยู่ใน `TUNING`
- `src/sim/map.ts` แมปทั้งหมด สร้างจากกล่อง
- `src/sim/aim.ts` ระบบช่วยเล็ง
- `src/sim/danger.ts` สัญญาณเตือนรอบจอ
- `src/render/view.ts` ภาพ 3 มิติ
- `src/input.ts` คีย์บอร์ด เมาส์ และระบบสัมผัส
- `src/ui.ts` HUD เมนู และหน้าตั้งค่า
- `src/net/` ข้อความเครือข่ายและการเชื่อมต่อฝั่งเกม
- `server/` เซิร์ฟเวอร์ห้อง รหัสห้อง คะแนน และการเกิดใหม่
