# ZEXOSAE

ต้นแบบเกมมุมมองบุคคลที่ 1 และ 3 บนเว็บ เน้นความเร็ว การโหนใย และการต่อสู้ ผู้เล่นมีเลือด 100 และใช้ทั้งใยกับท่าต่อสู้ได้

มีโหมดซ้อมคนเดียวและออนไลน์ 4 โหมด สูงสุด 16 คนต่อห้อง ยังไม่มีล็อกอิน Google ชื่อและคะแนนรวมจึงเก็บในเบราว์เซอร์ของผู้เล่น และจะหายถ้าล้างแคช

## ขึ้น Vercel

ทุกอย่างอยู่บน Vercel ไม่ต้องมีเซิร์ฟเวอร์เกมแยก Vercel ทำหน้าที่แสดงตัวเกม รายการห้อง และจับคู่ผู้เล่น ส่วนข้อมูลตอนเล่นวิ่งตรงระหว่างเบราว์เซอร์ผ่าน WebRTC โดยเบราว์เซอร์ของคนสร้างห้องเป็นโฮสต์

ต้องตั้งค่าครั้งเดียว:

1. ใน Vercel เปิดโปรเจกต์ แล้วไปที่แท็บ Storage
2. เพิ่ม Upstash for Redis จาก Marketplace และเชื่อมกับโปรเจกต์นี้
3. Redeploy

`api/rooms.ts` อ่าน `UPSTASH_REDIS_REST_URL` กับ `UPSTASH_REDIS_REST_TOKEN` หรือ `KV_REST_API_URL` กับ `KV_REST_API_TOKEN` ที่ Vercel ใส่ให้

## เล่นกับเพื่อน

หน้าแรกมีปุ่ม `เล่นทันที` ซึ่งสุ่มเข้าห้องสาธารณะที่มีคนเล่นอยู่และยังไม่เต็ม ถ้าไม่มีห้องเลยจะบอกว่าไม่มี โดยไม่สร้างห้องให้ ส่วน `ซ้อมคนเดียว` อยู่ล่างสุด

1. กด `ห้องทั้งหมด และสร้างห้อง` เลือกโหมด จำนวนผู้เล่น และห้องส่วนตัวหรือสาธารณะ แล้วกด `สร้างห้องใหม่`
2. เพื่อนใส่รหัสห้อง 4 ตัว หรือเข้าผ่านลิงก์ชวน ทุกห้องแสดงในบอร์ด `ห้องที่เปิดอยู่` แต่ห้องส่วนตัวจะมีรูปกุญแจและไม่แสดงรหัส ต้องใส่รหัสจากเจ้าของห้องเอง และไม่ถูกสุ่มเข้า
3. กด 👁 ข้างห้องเพื่อเข้าไปดูเฉยๆ คนดูไม่มีตัว ไม่โดนตี และไม่นับเป็นผู้เล่น คลิกหรือกด Space เพื่อเปลี่ยนคนที่ตามดู Shift ย้อนกลับ ห้องส่วนตัวต้องใส่รหัสเหมือนตอนเข้าเล่น ห้องหนึ่งรับคนดูได้ 8 คน
4. ระหว่างเล่น กด Esc แล้วกด `คัดลอกลิงก์ชวนเพื่อน` เพื่อส่งลิงก์ และกด Tab ค้างเพื่อดูคะแนน

กด `สุ่มเล่นกับผู้เล่นอื่น` เพื่อเข้าห้องสาธารณะที่ยังมีที่ว่าง ถ้าไม่มี ระบบจะสร้างห้องสาธารณะ 8 คนในโหมดสุ่มและรอคนอื่นเข้ามา ห้องสุ่มที่ขอพร้อมกันใช้การจองห้องร่วมกันเพื่อลดการแยกไปคนละห้อง ระบบนี้ยังไม่จัดอันดับตามฝีมือและไม่มีบอต

### โหมดออนไลน์

| โหมด | วิธีชนะ |
| --- | --- |
| เดธแมตช์เดี่ยว | KO ให้ครบ 15 ครั้งก่อนคนอื่น |
| เดธแมตช์ทีม | แบ่งทีมแดงกับน้ำเงิน ทีมแรกที่ได้ 25 KO ชนะ ยิงเพื่อนร่วมทีมไม่โดน |
| ยึดจุด | อยู่ในวงสีฟ้าคนเดียวเพื่อสะสมเวลาให้ครบ 45 วินาที ถ้ามีคนแย่งวงจะหยุดนับ |
| ชิงมงกุฎ | วิ่งเข้าไปเก็บมงกุฎ ถ้าคนถือถูก KO มงกุฎจะตกให้คนอื่นเก็บ ผู้ที่ถืออยู่เมื่อหมดเวลาชนะ |

ทุกรอบเริ่มเมื่อมีผู้เล่นอย่างน้อย 2 คน จำกัดเวลา 5 นาที ในโหมดคะแนน ถ้าหมดเวลาก่อนถึงเป้าจะตัดสินจากคะแนนสูงสุด ส่วนชิงมงกุฎตัดสินจากคนที่ถืออยู่เมื่อหมดเวลา ถ้าไม่มีคนถือจะไม่มีผู้ชนะ เมื่อจบรอบจะแสดงผล 8 วินาทีแล้วเริ่มรอบใหม่ ถ้าผู้เล่นเหลือคนเดียวจะกลับไปรอผู้เล่น

ข้อจำกัด:

- คนสร้างห้องต้องเปิดแท็บเกมไว้ ถ้าปิด ห้องจะจบและทุกคนกลับเมนู
- เน็ตของคนสร้างห้องรับภาระทั้งห้อง ยิ่งคนเยอะยิ่งต้องใช้เน็ตขาขึ้นแรง
- เกมต่อตรงระหว่างเบราว์เซอร์ ถ้าเล่นใน Wi-Fi เดียวกัน เราเตอร์ส่วนใหญ่ไม่ส่งการเชื่อมต่อวนกลับเข้ามาในบ้านเดียวกัน และ Wi-Fi บางที่กันเครื่องไม่ให้เห็นกัน เน็ตมือถือบางเจ้าก็บล็อก กรณีนี้ต้องมีเซิร์ฟเวอร์ส่งต่อ (TURN) ดูหัวข้อถัดไป
- Redis ฟรีมีโควตาคำสั่งต่อเดือน โฮสต์ใช้ระหว่างเปิดห้อง และเมนูออนไลน์ใช้ระหว่างเปิดหน้ารายการห้อง

### เปิดเซิร์ฟเวอร์ส่งต่อ (TURN)

ใช้ Cloudflare ได้ฟรีเดือนละ 1,000 GB:

1. ใน Cloudflare Dashboard ไปที่ Realtime แล้วสร้าง TURN key
2. คัดลอก Turn Token ID และ API Token
3. ใน Vercel ไปที่ Settings > Environment Variables แล้วใส่ `CLOUDFLARE_TURN_KEY_ID` กับ `CLOUDFLARE_TURN_API_TOKEN` แล้ว Redeploy

API `/api/rooms` จะสร้างรหัสผ่านอายุ 1 วันให้แต่ละคนเอง คีย์จึงไม่เคยถึงเบราว์เซอร์ ถ้าใช้ผู้ให้บริการอื่นให้ใส่ `TURN_URLS` (คั่นด้วยจุลภาค) `TURN_USERNAME` และ `TURN_CREDENTIAL` แทน ถ้าไม่ได้ตั้งอะไรไว้ เกมยังต่อตรงได้ตามปกติในเครือข่ายที่ไม่บล็อก

## สัญญาณเตือนรอบจอ

ถ้าศัตรูเล็งมาที่เราค้างไว้ และไม่มีกำแพงบัง ขอบจอฝั่งที่ศัตรูอยู่จะเรืองแสงสีแดง ขอบบนคือข้างหน้า ขอบล่างคือข้างหลัง ยิ่งศัตรูใกล้ยิ่งสว่าง ในโหมดซ้อม หุ่นจะผลัดกันเล็งมาเพื่อให้ฝึกหลบ ปรับค่าได้ใน `DANGER` ที่ `src/sim/danger.ts`

## หลุดออกนอกแมพ

ถ้าผู้เล่นข้ามกำแพงขอบแมพหรือตกลงใต้พื้น เกมจะพากลับเข้ามาทันที โหมดซ้อมกลับจุดเริ่มและรีเซ็ตรอบ ส่วนออนไลน์สุ่มจุดเกิดที่ห่างจากคนอื่น และไม่นับเป็นการตาย

## กติกาออนไลน์

- ทุกคนมีเลือด 100 ยิงใยโดนนัดละ 25 ต่อย เตะ และท่าอื่นๆ ทำดาเมจตามตาราง `HITS` ใน `src/sim/hits.ts` โฮสต์คิดดาเมจจากชนิดท่าเอง ไม่เชื่อตัวเลขจากคนตี
- ท่าที่ผลักหรือเหวี่ยงคนอื่น โฮสต์ส่งแรงไปให้เครื่องของคนโดนเท่านั้น และจำกัดแรงกับเวลามึนไว้ ระหว่างพุ่งหลบ ท่าใดๆ ก็ไม่โดน
- ฟื้นเลือดได้ทุก 3 วินาที
- ถูก KO แล้วจอเป็นสีเทาและบังคับตัวละครไม่ได้ จากนั้นเกิดใหม่ใน 3 วินาที โดยสุ่มจาก 28 จุดทั่วแมป ไม่ซ้ำจุดเดิม ห่างจากคนอื่นอย่างน้อย 30 เมตรเมื่อทำได้ และยิงไม่โดน 1.5 วินาทีแรก
- มุมซ้ายล่างแสดงปิงไปยังเจ้าของห้อง เขียวคือต่ำกว่า 80 ms เหลืองคือต่ำกว่า 150 ms และแดงคือสูงกว่านั้นหรือไม่มีการตอบกลับ
- ใยรัดแช่แข็งคนที่โดน 1.2 วินาที ใยจะขาด ขยับและยิงไม่ได้ แต่ยังหันกล้องได้ และทุกคนเห็นน้ำแข็งบนตัวคนนั้น
- เกมของคนยิงเป็นผู้รายงานการยิงโดน และเบราว์เซอร์โฮสต์ตรวจแค่ระยะกับอัตราการยิง จึงเหมาะกับเล่นกับเพื่อน แต่ยังกันโกงไม่ได้

เปลี่ยนปุ่มคอมได้ในหน้าตั้งค่า บนมือถือและไอแพดกด `ปรับปุ่มบนจอ` ในหน้าตั้งค่า เพื่อลากย้ายปุ่ม ปรับขนาด และปรับความเข้มได้

ไต่ได้ทุกผนังของตึก ระหว่างลอยอยู่ให้ดันเข้าหาผนัง หรือบนพื้นให้เงยหน้าแล้วเดินเข้าหา ตัวละครไม่ติดหนึบ ความเร็วยังอยู่และค่อยๆ ลดลง พุ่งชนแรงจะดีดขึ้นผนัง กด W แล้วหันกล้องเพื่อไต่ไปทางนั้น ถ้าไม่กดอะไรจะไถลลงช้าๆ ดันออกจากผนังเพื่อปล่อย กระโดดเพื่อดีดตัวออกไปทางที่มอง และถ้าเงยหน้าอยู่จะกระโดดขึ้นตามผนัง พอถึงขอบบนจะดีดขึ้นดาดฟ้าเอง ปรับค่าได้ใน `wall` ที่ `TUNING` ใน `src/sim/player.ts`

ชนผนังตรงๆ แรงเกิน 26 เมตรต่อวินาที เช่นโหนใยหรือพุ่งเข้าใส่เต็มแรง จะเกาะไม่ทัน ตัวจะกระเด้งออกจากผนัง ใยหลุด และมึนอยู่ 0.7 วินาที ระหว่างนั้นเกาะผนัง ยิงใย และพุ่งไม่ได้ บังคับกลางอากาศได้นิดเดียว ปรับได้ที่ `wallSlam` ใน `TUNING`

| เหวี่ยงโยน | กด E ค้างใส่ศัตรูที่อยู่ใกล้ ศัตรูกระเด็นไปทางที่มอง ถ้าลอยอยู่จะเหวี่ยงลงพื้น ถ้ากระเด็นชนผนังจะติดผนัง จากนั้นแตะ E ต่ออีกได้ 3 ครั้งเพื่อเหวี่ยงรอบตัว |
| กระโจนจากผนัง | คลิกซ้ายตอนเกาะผนัง พุ่งเข้าหาศัตรูแล้วกระแทกคนรอบๆ ด้วย |
| ทุบพื้น | กด C ตอนลอยสูงกว่า 3 เมตร ยิ่งตกสูงยิ่งแรงและวงกว้าง |
| ใยรัดติดผนัง | ใยรัดโดนศัตรูที่อยู่ติดผนัง จะติดนานเป็นสองเท่า |
| ดึงกล่องมาปา | เล็งกล่องไม้แล้วกด Q กล่องจะลอยมาที่มือแล้วปาไปทางที่เล็ง กล่องเกิดใหม่ใน 10 วินาที |
| โฟกัส | แถบสีฟ้าใต้แถบเลือด ได้จากการตีโดน (กลางอากาศได้เป็นสองเท่า) หลบเป๊ะ ปล่อยใยเป๊ะ และท่าเท่ |
| ฟื้นเลือด | กด F ตอนอยู่บนพื้นหรือเกาะผนัง ใช้โฟกัส 1 ช่อง ได้เลือด 35 |
| ท่าปิดฉาก | กด F ใกล้ศัตรูตอนโฟกัสมีอย่างน้อย 2 ช่อง ดาเมจ 55 |
| ท่าเท่กลางอากาศ | กด F ตอนลอยอยู่ ได้ 3 ท่าต่อการลอย 1 รอบ แต่ละท่าได้โฟกัส |

ค่าทั้งหมดปรับได้ใน `MOVES` ที่ `src/sim/moves.ts`

ใยจะเกาะจุดกลางจอก่อน ถ้าเล็งพลาดเล็กน้อยจะหาจุดใกล้ๆ ให้ และถ้าปิดช่วยเล็งจะเกาะจุดกลางจอเท่านั้น ระหว่างลอยอยู่ ให้กด W ค้างแล้วหันเมาส์เพื่อเลี้ยวทิศทาง

ช่วยเล็งไม่ขยับกล้องหรือทำให้เมาส์หนืด ถ้ากระสุนพลาดเล็กน้อยจะเบี่ยงเข้าเป้า ปรับค่าได้ใน `AIM` ที่ `src/sim/aim.ts` และปิดได้ในหน้าตั้งค่า กรอบเล็งแสดงเฉพาะโหมดซ้อม

## แมพ

เลือกช่วงเวลาของเมืองได้ในหน้าตั้งค่า: เย็น (ค่าเริ่มต้น) กลางวัน กลางคืน หรือหมุนเวียนอัตโนมัติ ตอนกลางคืนมีดาว แสงจันทร์ หน้าต่างตึกเปิดไฟบ้างดับบ้าง ซึ่งแต่ละตึกได้รูปแบบของตัวเองและไม่กระพริบ เสาไฟข้างทางส่องเป็นวงบนทางเท้า และรถเปิดไฟหน้าไฟท้าย แบบหมุนเวียนจะเปลี่ยนตามนาฬิกา ทุกคนในห้องจึงเห็นฟ้าเดียวกัน ค่าแต่ละช่วงเวลาอยู่ที่ `LOOKS` ใน `src/render/lighting.ts`

ยิ่งเร็ว ภาพยิ่งกว้างขึ้นและกล้องมุมบุคคลที่ 3 ถอยห่างออก ตอนดิ่งลงเร็ว ตัวละครจะหันหัวลงแนบแขนขาแบบนักโดดร่ม และจอสั่นตามแรงลม ยิ่งดิ่งเร็วยิ่งสั่น ส่วนตอนโหนหรือวิ่งจอนิ่ง แต่กล้องถอยได้ไม่เกิน 5.8 เมตร ตัวละครจึงไม่เล็กจนบังคับยาก ปิดได้ด้วยตัวเลือกลดการเคลื่อนไหวของกล้อง

แมพชื่อ Spire district เป็นเมืองยามเย็นขนาด 900 × 900 เมตร รอบย่านกลางเป็นตารางถนน: ถนนกว้าง 16 เมตรมีเส้นกลางถนนและทางม้าลายทุกแยก ทุกบล็อกมีทางเท้า และแต่ละบล็อกจัดต่างกัน คือตึกสูงหลังเดียว ตึกคู่ ตึกเล็กสี่หลัง ตึกยาวกับตึกเตี้ย ตึกล้อมลาน สวนสาธารณะที่มีต้นไม้ หรือลานจอดรถ ใจกลางเมืองตึกสูงกว่า ชานเมืองเตี้ยลงและมีสวนมากขึ้น มีรถจอดริมถนน ซึ่งเตี้ยพอกระโดดข้ามได้ และมีรถวิ่งตามถนนเป็นฉากประกอบ ซึ่งชนไม่ได้ และทุกคนเห็นรถคันเดียวกันในตำแหน่งเดียวกันเพราะใช้เวลาเดียวกัน เมืองสร้างจากค่าตั้งต้นตายตัวใน `src/sim/city.ts` ทุกคนจึงได้เมืองเดียวกัน แนวตึกต่อเนื่องยังล้อมขอบเมืองเหมือนเดิม กลางเมืองยังมีเสาให้เกาะใย ถนนวงรอบ และ 8 บล็อกที่เล่นต่างกัน เพราะไต่ผนังได้ทุกที่จึงไม่ต้องมีแท่นหรือแผงเสริม

- ทิศเหนือ: ห้างที่มีอุโมงค์วิ่งทะลุ
- ทิศใต้: อาคารอพาร์ตเมนต์ จุดเริ่มโหมดซ้อม
- ทิศตะวันออก: อาคารจอดรถ มีชั้นให้วิ่งลอด
- ทิศตะวันตก: สนามกีฬา
- มุมตะวันตกเฉียงเหนือ: ตึกกระจกสูง
- มุมตะวันออกเฉียงเหนือ: ตึกอิฐ
- มุมตะวันออกเฉียงใต้: ตึกแฝด มีคานเชื่อมให้เกาะใย
- มุมตะวันตกเฉียงใต้: โรงแรมขั้นบันได

ตึกแต่ละหลังได้สีอ่อนต่างกัน เพื่อไม่ให้ตึกข้างกันดูเหมือนก๊อปกัน ถนน รถ และต้นไม้วาดใน `src/render/streets.ts` ตึกส่วนใหญ่และตึกไกลๆ ใช้โมเดลจาก Kenney โดยตัดของบนดาดฟ้าออก เพราะไม่มีกล่องชน ส่วนสิ่งที่มีรูปทรงเฉพาะ เช่น เสากลาง อาคารจอดรถ และคาน สร้างจากโค้ดใน `src/render/arena.ts` เกมเตรียมโมเดลเมืองและตัวละครทั้งหมดก่อนเข้าเมนู และใช้โมเดลตึกชุดเดียวตลอดแมพ หากโหลดไม่สำเร็จสามารถกดลองอีกครั้งได้ ตัวละครอยู่ใน `src/render/character.ts` และได้สีชุดตามหมายเลขในห้อง

## โครงสร้าง

- `src/sim/` ฟิสิกส์และกติกา ไม่พึ่ง Three.js หรือ DOM เพื่อให้เซิร์ฟเวอร์ออนไลน์นำไปใช้ซ้ำได้
- `src/sim/player.ts` ค่าปรับความรู้สึกทั้งหมดอยู่ใน `TUNING`
- `src/sim/map.ts` แมปทั้งหมด สร้างจากกล่อง
- `src/sim/aim.ts` ระบบช่วยเล็ง
- `src/sim/danger.ts` สัญญาณเตือนรอบจอ
- `src/render/view.ts` ภาพ 3 มิติ
- `src/render/kenney.ts` โหลดโมเดลและครอบตึกให้ตรงกล่องชน
- `src/render/shells.ts` เลือกโมเดลให้แต่ละตึก
- `src/render/hero.ts` ตัวละครที่มีท่าทางจริง
- `src/render/body-pose.ts` เลือกท่าตามการเคลื่อนที่
- `src/render/camera-motion.ts` การสั่นไหวของมุมมอง
- `src/render/chase-camera.ts` กล้องบุคคลที่ 3 แบบยืดหยุ่น
- `src/input.ts` คีย์บอร์ด เมาส์ และระบบสัมผัส
- `src/ui.ts` HUD เมนู และหน้าตั้งค่า
- `src/control-editor.ts` หน้าปรับปุ่มบนมือถือ
- `src/sim/moves.ts` ท่าใยและท่าต่อสู้ทั้งหมด
- `src/sim/city.ts` ผังถนนและบล็อกรอบเมือง
- `src/render/streets.ts` ถนน ทางเท้า รถ ต้นไม้ และรถวิ่ง
- `src/sim/hits.ts` ตารางดาเมจ ระยะ และคูลดาวน์ ที่ทั้งเกมและโฮสต์ใช้ร่วมกัน
- `src/mobile.ts` กันการซูมหน้าเว็บบนไอแพดและไอโฟน
- `src/net/` ข้อความเครือข่ายและการเชื่อมต่อฝั่งเกม
- `src/net/room.ts` กติกาห้อง คะแนน และการเกิดใหม่ ทำงานในเบราว์เซอร์โฮสต์
- `api/rooms.ts` รายการห้องและการจับคู่ผู้เล่นบน Vercel
